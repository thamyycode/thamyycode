## 🦄 O que eu desenvolvi
Neste projeto, criei uma arquitetura robusta em **Python** para gerenciar a estrutura interna de organizações:

*   **Gestão Hierárquica:** Separação entre Admins, Gestores e Colaboradores.
*   **Fluxo de Dados:** Organização de tarefas distribuídas entre os times.
*   **Automação:** Scripts para entrada de novos membros e atualização de cargos.
